# 🔔 Sons de Notificação

Coloque aqui os arquivos de áudio para as notificações do sistema.

## Formatos recomendados

| Formato | Extensão | Compatibilidade |
|---------|----------|-----------------|
| **MP3** | `.mp3`   | ✅ Todos os navegadores e dispositivos |
| **OGG** | `.ogg`   | ✅ Chrome, Firefox, Edge (❌ Safari) |
| **WAV** | `.wav`   | ✅ Todos (arquivo maior) |

> **Recomendação:** use **MP3** para máxima compatibilidade.

## Nomes esperados

| Arquivo | Uso |
|---------|-----|
| `notificacao.mp3` | Som principal — push, avisos do mural, notificações gerais |
| `receber.mp3`     | Mensagem recebida no chat (opcional) |
| `enviar.mp3`      | Mensagem enviada no chat (opcional) |

## Dicas

- Sons curtos (0,5 a 2 segundos) funcionam melhor
- Volume moderado — o sistema já controla o gain
- Evite arquivos maiores que 100 KB
