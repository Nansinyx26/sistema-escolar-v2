Códigos de Backup 2FA

Segundo fator que não depende de e-mail. Use quando o provedor estiver indisponível ou a pessoa perder acesso à caixa de entrada.

1. Escolha a conta

2. Gerar um lote novo

Gera 8 códigos de uso único. Invalida o lote anterior — códigos antigos param de funcionar na hora.

2. Código fixo de 2FA

Isto é mais fraco que os códigos de uso único. Um código fixo é reutilizável: quem o vir uma vez entra sempre, até alguém trocá-lo. Use enquanto o e-mail estiver indisponível e remova quando o envio voltar.

2. Enviar código de recuperação de senha

Dispara o mesmo fluxo do “Esqueci minha senha” da tela de login. O código de 6 dígitos vai para o e-mail da própria pessoa e vale 15 minutos.

O código não aparece aqui, e isso é proposital: quem redefine a senha precisa ser quem tem acesso à caixa de e-mail do titular. Se o administrador pudesse ler o código, poderia trocar a senha de qualquer conta sem o dono saber.
